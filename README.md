One deadpan weather forecast for a city that does not exist, in a single line of 145 characters: over Kestrel Falls, scattered showers of unmailed letters this afternoon, with a 70 percent chance of damp apologies by evening — read exactly as if it were Tuesday's weather.

## Run it

```sh
python3 main.py
```

It validates the line (one line, 1–160 characters) and writes it to `/output/entry.txt`.
